# Decode-Labs-Internship-Project-2-Expesne-Tracker
- A simple command-line Python program that helps you track expenses, calculate totals and generate a summary of basic statistics
## features
- Add multiply expenses interactively
- input validation
- Tracks total-expesnes
- Displays Average, Smallest expense, Largest expense, Number of transactions
- Loop continues until the user decides to stop
## Technologies used
Python 3
## How to run 
- Clone the repository
- Open the terminal
- Run:
```bash
python main.py
```
